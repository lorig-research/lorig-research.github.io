# Lo-Rig Project Mentioned in Kuensel Article on Gongdue Kha

**04 July 2026**

The Lo-Rig project was mentioned in a recent article in *Kuensel*, Bhutan's national newspaper, titled **"Gongdue Kha going extinct in Mongar"**. The article discusses the endangered status of Gongdue Kha and highlights current efforts to document and preserve the language. The Lo-Rig project is mentioned as part of these ongoing documentation efforts.

This media coverage helps draw attention to the urgency of language documentation work in Bhutan and to the importance of sustained collaboration with speaker communities in documenting, preserving, and promoting endangered languages.
