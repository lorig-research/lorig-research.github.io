# Network Meeting on Automating Language Documentation and Description

**17–19 September 2025**

Between 17 and 19 September 2025, Lo-Rig Principal Investigator Tim Bodt participated in a network meeting on **"Automating language documentation and description"**, held at Uppsala University in Sweden.

The meeting brought together around 20 academic researchers working in language documentation and human language technologies. Participants discussed how language technologies could be better incorporated into the work of linguists documenting and describing endangered languages.

This meeting contributed to wider collaboration and knowledge exchange around the role of technological tools in supporting language documentation and description.
